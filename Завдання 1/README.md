# Завдання 2 — Автентифікація та авторизація (JWT + RBAC)

Реалізація на Node.js/Express для автентифікації користувачів за допомогою JWT та контролю доступу на основі ролей (RBAC).

## Структура проєкту
- `.env` — конфігураційні змінні оточення.
- `server.js` — основний серверний файл з ендпоінтами та імітацією БД.
- `middleware/auth.js` — middleware для перевірки JWT (`authenticate`) та валідації ролей (`authorize`).
- `package.json` — залежності проєкту.

## Інструкція із запуску
1. Розпакуйте архів та відкрийте папку в терміналі.
2. Встановіть залежності: `npm install`
3. Запустіть сервер: `npm start`
