# Завдання 3 — Тестування (Jest)

Реалізація Unit-тестів для функції розрахунку знижки `calculateDiscount`.

## Структура проєкту
- `discount.js` — файл із початковою функцією розрахунку знижки.
- `discount.test.js` — набір тестів, що повністю покриває всі вимоги завдання + додаткові крайові умови.
- `package.json` — конфігурація проєкту та запуск Jest.

## Як запустити тести локально
1. Розпакуйте архів та відкрийте папку в терміналі.
2. Встановіть Jest: `npm install`
3. Запустіть тести: `npm test`
